# Verto

A modern Material Design 3 unit, global currency, and live Gold & Silver converter for Android with offline caching, interactive 5-year charts, regional auto-defaults, and 10 languages.

## Key Features
- **Unit Converter:** 13 categories (Length, Mass, Temperature, Area, Volume, Speed, Time, Digital Data, Pressure, Energy, Power, Angle, Fuel Economy) with full equivalent-units breakdown.
- **Global Currency Converter:** 165+ world currencies, live rate sync, offline Room fallback, saved conversion pairs, and interactive **7D / 1M / 3M / 1Y / 5Y** historical trend charts.
- **Gold & Silver Tracker:** Live spot prices in 190+ country markets, purity breakdown (`24K`–`14K` gold, `999`–`800` silver), bullion value calculator, and chart unit/purity selectors (**Troy Oz / Gram / 8g Coin** + karat/fineness filters).
- **Location-Aware Defaults (Optional):** Automatically detects region via coarse location to set default units, currency, and local bullion market—all manually overridable.
- **Customizable UI:** 10 languages (including RTL Arabic), Light/Dark/System theme, configurable Navigation Bar position (**Bottom / Top / Left / Right**), and customizable start screen.

## Google Play Console Checklist (Data Safety & Store Setup)
1. **Privacy Policy URL:** `https://github.com/Moheyeldin70/Verto/blob/main/PRIVACY_POLICY.md`
2. **App Access:** All functionality is available without login/credentials.
3. **Ads:** Contains no ads.
4. **Data Safety Form:**
   - Does your app collect or share any of the required user data types? **No** *(coarse location is processed transiently on-device via Android Geocoder to pick local defaults and is never transmitted to developer servers)*.
   - Alternatively, if declaring transient on-device usage: mark **Approximate location** as *Not collected / Ephemeral on-device only* and *Not shared*.
5. **Store Listing Visuals Needed:**
   - App icon (`512 × 512` PNG)
   - Feature graphic (`1024 × 500` PNG/JPG)
   - Phone screenshots (2–8 screenshots)
